# 我是面试官 - 系统概要设计文档

## 1. 系统概述

"我是面试官"是一款基于大语言模型（LLM）的智能面试助手工具，以 CLI 命令行工具形式分发（npm 包 `imivr-bobfintech`），帮助面试官高效地进行技术面试。系统通过 AI 分析候选人简历与岗位 JD 要求，自动生成梯度化的面试问题清单，并在面试后根据评分给出综合评价与职级推荐。

**核心特点**：本地优先存储、多工种覆盖（7个预设工种）、AI 流式出题、梯度化难度体系（L1-L5）、标准化职级评定（P3-P7）。

## 2. 系统架构

### 2.1 整体架构

系统采用 **CLI + Express 服务端 + React SPA 前端** 的三层架构：

```
┌──────────────────────────────────────────────────────────────┐
│                     CLI 命令行层 (Commander.js)                │
│     start（启动服务） / init（安装引导） / doctor（健康检查）    │
│     config（配置管理） / uninstall（卸载）                     │
├──────────────────────────────────────────────────────────────┤
│                    Express 服务端                              │
│     REST API (/api/fs/*) — 文件读写、目录操作、配置管理         │
│     简历解析 (markitdown-ts) — PDF/Word → Markdown            │
│     静态文件服务 — React SPA 前端资源                          │
├──────────────────────────────────────────────────────────────┤
│                    React SPA 前端                              │
│     React 18 + TypeScript + Ant Design 5 + Zustand            │
│     7 个页面路由，覆盖工作空间→面试→评分→评定→报告全流程        │
├──────────────────────────────────────────────────────────────┤
│                    本地文件系统 (Markdown)                     │
│     {workspaceRoot}/{job_role}/                               │
│     ├── workspace.md         工作空间配置                      │
│     ├── question-bank/       题库（L1-L5 分级）                │
│     ├── interviews/          面试记录（每场一个子目录）          │
│     └── templates/           JD 模板                          │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端框架 | React 18 + TypeScript |
| UI 组件库 | Ant Design 5 |
| 路由 | React Router v6 |
| 状态管理 | Zustand |
| 服务端 | Express 5 |
| CLI 框架 | Commander.js + @clack/prompts |
| Markdown 解析 | gray-matter |
| 简历解析 | markitdown-ts |
| AI 引擎 | OpenAI 兼容 API（finna/deepseek/qwen/openai/custom） |
| 语音 | MediaRecorder API + AI ASR |
| 构建 | Vite（前端）+ tsup（CLI） |
| 运行环境 | Node.js >= 20 |

### 2.3 架构设计理念

**本地优先（Local-first）**：所有数据存储在用户本地文件系统，以 Markdown 文件（YAML Front Matter + 正文）形式组织。数据可离线查看、Git 版本控制、直接文本编辑。

**前后端一体化**：CLI 启动时同时启动 Express 服务端和静态文件服务，前端通过 `/api/fs/*` REST API 与服务端通信，所有文件操作由服务端代理执行。

**工作空间隔离**：每个工种独立工作空间目录，包含完整的工种配置、题库、面试记录、JD 模板，工作空间之间数据完全隔离。

## 3. 模块架构

### 3.1 模块分层

```
┌─────────────────────────────────────────────┐
│                 页面层 (pages/)               │
│  WorkspaceList / WorkspaceDetail             │
│  InterviewList / InterviewDetail             │
│  InterviewInProgress / QuestionBank / Settings│
├─────────────────────────────────────────────┤
│               业务模块层 (modules/)            │
│  workspace / interview / jd / question-bank  │
│  resume / scoring / assessment / report      │
├─────────────────────────────────────────────┤
│                核心层 (core/)                 │
│  filesystem / markdown / ai / plugin         │
├─────────────────────────────────────────────┤
│              基础设施层                       │
│  stores (Zustand) / types / utils / components│
└─────────────────────────────────────────────┘
```

### 3.2 模块职责

| 模块 | 职责 |
|------|------|
| workspace | 工作空间 CRUD、预设初始化、统计校验 |
| interview | 面试 CRUD、状态流转（pending→in_progress→completed/cancelled） |
| jd | 岗位描述 CRUD、校验 |
| question-bank | 题库管理（按 L1-L5 分级，Markdown 文件存储） |
| resume | 简历上传、markitdown-ts 解析、AI 结构化提取 |
| scoring | 逐题评分（0-10）、AI 辅助评分（1-5）、面试官四维度评价、手动加分 |
| assessment | 综合评定（AI/手动/规则兜底）、职级推荐、录用建议 |
| report | 报告模板生成（default/detailed/summary）、版本管理（.bak 备份） |

### 3.3 核心层

| 模块 | 职责 |
|------|------|
| filesystem | 前端与服务端之间的文件操作代理层（16 个 REST API 端点） |
| markdown | YAML Front Matter 解析/序列化、Markdown 结构提取 |
| ai | AI 引擎配置与调用（configureAI / callAI / callAIWithJSON） |
| plugin | 插件系统，工种专属 Prompt 模板管理 |

## 4. 数据架构

### 4.1 存储模型

所有业务数据以 **Markdown 文件** 形式存储，文件头部使用 **YAML Front Matter** 承载结构化元数据，正文承载自由文本内容。

**面试目录文件结构**（每场面试一个子目录）：

| 文件 | 存储内容 |
|------|----------|
| interview.md | 面试基本信息（候选人、面试官、日期、工种、目标职级、状态、JD关联） |
| resume.md | AI 结构化解析后的简历数据 |
| questions.md | AI 生成的面试问题清单（含类型、难度、参考答案） |
| answers.md | 答题记录（候选人回答、面试官评分、AI评分） |
| assessment.md | 等级评定结果（推荐职级、综合得分、录用建议） |
| report.md | 面试评估报告 |
| tags.md | AI 生成的候选人特征标签（7大类） |

### 4.2 核心数据流

```
简历文件 ──▶ markitdown-ts ──▶ 简历文本 ──▶ AI 解析 ──▶ resume.md
                                                        │
JD 模板 ──▶ jd-template.md ──▶ 岗位要求 ──────────────┤
                                                        │
题库文件 ──▶ questions.md ──▶ 题库参考 ────────────────┤
                                                        │
                                                        ▼
                                              AI 问题生成 ──▶ questions.md
                                                        │
                                                        ▼
                                             面试执行 ──▶ answers.md
                                                        │
                                                        ▼
                                             评分计算 ──▶ assessment.md
                                                        │
                                                        ▼
                                             报告生成 ──▶ report.md
```

### 4.3 评分模型

```
综合得分 = 候选人平均分 + 手动加分(-5~+5) + 面试官评价平均分

候选人平均分 = Σ(各题面试官评分) / 题目数
面试官评价平均分 = (沟通 + 项目 + 潜力 + 价值观) / 4
```

### 4.4 职级评定规则（兜底逻辑）

| 条件 | 职级建议 | 录用建议 |
|------|----------|----------|
| 综合得分 >= 8.5 | 晋升一级 | — |
| 综合得分 >= 7 | — | 通过 |
| 综合得分 >= 4 | 保持当前 | 待定 |
| 综合得分 < 4 | 降级 | 不通过 |

## 5. CLI 工具

| 命令 | 说明 |
|------|------|
| `imivr start` | 启动服务（Express + 静态文件），自动查找可用端口 |
| `imivr init` | 安装引导，配置工作目录和 AI 模型 |
| `imivr doctor` | 健康检查（配置目录、工作空间、模型状态） |
| `imivr config` | 查看/设置/获取配置项 |
| `imivr uninstall` | 卸载清理 |

配置文件位置：`~/.imivr/imivr.json`，包含工作目录路径、AI 模型列表（问答+语音）、主题配置。

## 6. 前端路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | WorkspaceList | 工作空间列表（7个预设工种） |
| `/workspaces/:jobRole` | WorkspaceDetail | 工作空间详情（JD管理 + 题库入口） |
| `/workspaces/:jobRole/interviews` | InterviewList | 面试记录列表 |
| `/workspaces/:jobRole/interviews/:id` | InterviewDetail | 面试详情（简历/问题/结果三Tab） |
| `/workspaces/:jobRole/interviews/:id/in-progress` | InterviewInProgress | 全屏面试执行 |
| `/workspaces/:jobRole/questions` | QuestionBank | 题库管理 |
| `/settings` | Settings | 系统设置 |
