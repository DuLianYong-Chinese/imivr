# 02 - 简历管理模块

## 2.1 模块概述

简历管理模块负责候选人简历的上传、解析、存储和查询。支持 PDF、Word 格式的简历文件，通过 `markitdown-ts` 将文档转换为 Markdown 文本，再通过 AI 技术将简历内容结构化提取，并以 Markdown 文件形式存储在面试目录中。

## 2.2 模块目标
- 支持 PDF、Word 格式的简历文件上传
- 自动解析简历内容并结构化
- 提供简历信息的查看功能
- 与面试流程无缝集成

## 2.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| RES-001 | 上传简历 | 上传简历文件到指定面试记录 | P0 |
| RES-002 | 简历解析 | markitdown-ts 转换 + AI 结构化解析 | P0 |
| RES-003 | 查看简历 | 查看已解析的简历信息 | P0 |
| RES-004 | 删除简历 | 删除简历文件及解析结果 | P1 |

## 2.4 功能详细说明

### RES-001 上传简历

**输入**：interviewId + resumeFile

**处理逻辑**：验证面试目录 → 校验文件格式和大小 → 保存文件 → 触发解析流程

**支持格式**：PDF、DOC、DOCX，≤10MB

### RES-002 简历解析

**处理逻辑**：
1. 调用 `markitdown-ts` 将 PDF/Word 文档转换为 Markdown 文本
2. 清洗转换后的文本（去除多余空行、乱码字符）
3. 调用 AI 结构化解析（从插件加载 Prompt）
4. 生成 `resume.md` 保存到面试目录

**AI 解析提取内容**：
- 基本信息（姓名、联系方式、邮箱）
- 教育背景（学校、专业、学历、时间）
- 工作经历（公司、职位、时间、主要职责）
- 技术技能（编程语言、框架、工具）
- 项目经验（项目名称、技术栈、个人贡献）

### RES-003 查看简历 / RES-004 删除简历

使用 `gray-matter` 解析 resume.md 文件，支持查看和删除操作。

## 2.5 数据文件规范

**存储位置**：`{workspaceRoot}/{job_role}/interviews/{date}-{name}/resume.md`

```markdown
---
candidate_name: 张三
contact: 13800138000
email: zhangsan@example.com
work_years: 2
education:
  - school: 某某大学
    major: 计算机科学与技术
    degree: 本科
    start_date: "2018-09"
    end_date: "2022-06"
skills: [JavaScript, Vue, React, TypeScript, Node.js]
parsed_at: 2026-04-17T10:30:00Z
parse_status: success
---

# 候选人简历 - 张三
（详细内容）
```

## 2.6 非功能需求

- 上传响应时间：< 3秒，解析：< 5秒，查看：< 1秒
- 文件类型白名单校验，AI 调用仅发送必要文本
- 简历文件完全存储在本地，支持离线查看
