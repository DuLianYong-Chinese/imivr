# 03 - JD管理模块

## 3.1 模块概述

JD（Job Description）管理模块负责管理岗位描述的配置信息。包括工种类型选择、职级范围设定、技能要求定义、考察维度配置等。JD 配置以 Markdown 文件形式存储在工作空间的 `templates/` 目录中，面试时可关联 JD 以指导 AI 出题方向。

## 3.2 模块目标
- 提供标准化的岗位描述配置模板
- 支持多工种差异化配置
- 灵活定义考察维度和权重
- 与问题生成模块无缝集成

## 3.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| JD-001 | 创建JD配置 | 创建新的岗位描述配置 | P0 |
| JD-002 | 查看JD配置 | 查看岗位描述详情 | P0 |
| JD-003 | 更新JD配置 | 修改岗位描述配置 | P0 |
| JD-004 | 删除JD配置 | 删除岗位描述配置 | P1 |
| JD-005 | JD配置列表 | 查看所有JD配置 | P1 |
| JD-006 | JD配置校验 | 校验配置完整性 | P2 |

## 3.4 功能详细说明

### JD-001 创建JD配置

**输入**：
```typescript
interface CreateJDInput {
  job_role: string
  position_name: string
  target_level: string
  level_range: string[]
  required_skills: string[]
  preferred_skills?: string[]
  min_experience?: number
  education_requirement?: string
  evaluation_dimensions: Dimension[]
}
```

**处理逻辑**：校验工种和职级 → 校验权重总和 → 生成配置文件 → 保存到 templates/ 目录

### JD-002 查看 / JD-003 更新 / JD-004 删除

读取/更新/删除 JD 配置文件，支持按 jdId 查找。

### JD-005 JD配置列表

遍历 `templates/` 目录，读取 YAML Front Matter 返回列表。

### JD-006 JD配置校验

检查必填字段、职级范围、权重总和、技能列表格式。

## 3.5 数据文件规范

**存储位置**：`{workspaceRoot}/{job_role}/templates/jd-{jdId}-template.md`

```markdown
---
jd_id: jd-20260417-001
job_role: frontend_dev
position_name: 高级前端开发工程师
target_level: P6
level_range: [P5, P6, P7]
required_skills: [JavaScript, Vue/React, TypeScript, 前端工程化]
preferred_skills: [Node.js, 微前端, 性能优化]
evaluation_dimensions:
  - name: 基础知识, weight: 0.2
  - name: 框架原理, weight: 0.25
  - name: 工程化, weight: 0.2
  - name: 性能优化, weight: 0.2
  - name: 项目经验, weight: 0.15
created_at: 2026-04-17T10:00:00Z
---

# JD配置 - 高级前端开发工程师
（详细岗位要求）
```

## 3.6 非功能需求

- 创建响应时间：< 1秒，列表：< 1秒
- 配置变更日志记录
- JD 配置完全存储在本地，可直接用文本编辑器修改
