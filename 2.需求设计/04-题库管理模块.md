# 04 - 题库管理模块

## 4.1 模块概述

题库管理模块负责管理各工种的面试题目库。题库按难度等级（L1-L5）分类组织，每个难度等级目录下有一个 `questions.md` 文件存储该难度的所有题目。题目为纯 Markdown 格式，由用户在题库管理页面编辑维护。AI 出题时会读取对应难度等级的题库内容作为参考。

## 4.2 模块目标
- 提供结构化的题库管理功能
- 支持按难度等级分类组织
- 支持手动编辑和上传 Markdown 文件
- 提供题目搜索和查看功能

## 4.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| QB-001 | 获取题库列表 | 按工种和难度获取题目列表 | P0 |
| QB-002 | 查看题库内容 | 查看指定难度等级的题库内容 | P0 |
| QB-003 | 编辑题库 | 直接编辑题库 Markdown 内容 | P0 |
| QB-004 | 上传题库文件 | 上传 Markdown 文件追加或覆盖题库 | P1 |
| QB-005 | 题目搜索 | 在题库中搜索关键词并高亮 | P1 |
| QB-006 | 题目统计 | 统计题库数量和分布 | P2 |

## 4.4 功能详细说明

### QB-001 获取题库列表

**输入**：jobRole

**处理逻辑**：扫描 question-bank/ 目录 → 读取各难度等级的 questions.md → 返回按难度分组的题目列表

### QB-002 查看题库内容

**输入**：jobRole + difficulty

**处理逻辑**：读取对应难度等级的 questions.md → 渲染 Markdown 内容 → 支持搜索高亮和上下导航

### QB-003 编辑题库

**输入**：jobRole + difficulty + content

**处理逻辑**：直接写入 questions.md 文件

### QB-004 上传题库文件

**输入**：jobRole + difficulty + file + mode（append/overwrite）

**处理逻辑**：读取上传的 Markdown 文件 → 追加或覆盖到对应难度等级的 questions.md

### QB-005 题目搜索 / QB-006 题目统计

支持关键词搜索高亮、按难度统计题目数量。

## 4.5 数据文件规范

**存储位置**：`{workspaceRoot}/{job_role}/question-bank/{L1-L5}-{难度名称}/questions.md`

题库文件为纯 Markdown 格式，由用户自由组织内容结构。AI 出题时会将对应难度等级的题库内容作为参考上下文。

## 4.6 非功能需求

- 列表响应时间：< 2秒，搜索：< 3秒
- 支持题库数量：≥ 1000
- 题库完全存储在本地，可直接用文本编辑器查看和修改
