# 05 - 问题生成模块

## 5.1 模块概述

问题生成模块是系统的核心 AI 功能之一，负责根据候选人简历、JD 配置和工种信息，自动生成梯度化的面试问题清单。模块支持流式生成（SSE），结合题库参考和候选人特征标签，按难度分布比例出题。

## 5.2 模块目标
- 基于简历和 JD 智能生成面试问题
- 按难度等级（L1-L5）梯度分布
- 覆盖工种核心考察维度
- 结合题库参考和 AI 生成，保证问题质量
- 支持流式生成，实时展示出题过程

## 5.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| QG-001 | 生成问题清单 | AI 流式生成面试问题清单 | P0 |
| QG-002 | 查看问题清单 | 查看已生成的问题清单 | P0 |
| QG-003 | 继续出题 | 在已有问题基础上补充新题 | P0 |
| QG-004 | 标签选择出题 | 按候选人特征标签定向出题 | P1 |
| QG-005 | 难度分布调整 | 可视化调整各难度等级题目占比 | P1 |

## 5.4 功能详细说明

### QG-001 生成问题清单

**输入**：
```typescript
interface GenerateQuestionsInput {
  interviewId: string
  jobRole: string
  questionCount: number
  difficultyDistribution: Record<string, number>  // L1-L5 各占比
  selectedTags?: string[]  // 候选人特征标签
  tagQuestionCounts?: Record<string, number>  // 每个标签出题数
}
```

**处理逻辑**：
1. 读取候选人简历内容（resume.md）
2. 读取关联的 JD 配置（如有）
3. 读取对应难度等级的题库内容作为参考
4. 读取已出题目列表（防止重复出题）
5. 从插件加载工种专属 Prompt 模板
6. 调用 AI 模型流式生成问题（SSE streaming）
7. 解析 AI 返回的格式化问题（类型/题目/答案）
8. 按难度分布比例分配难度等级
9. 合并已有题目与新题目，写入 questions.md

**问题格式**：
```
类型：[技术领域名称]
题目：[问题内容，50字以内]
答案：[参考答案，50-200字，逐条列举]
```

### QG-002 查看问题清单

读取 questions.md，按类型和难度分组展示问题列表。

### QG-003 继续出题

在已有问题基础上，传入已出题目列表防止重复，调用 AI 补充新题。

### QG-004 标签选择出题

从候选人特征标签（tags.md）中选择出题方向，每个标签可配置出题数量（1-10道），AI 按标签方向定向生成问题。

### QG-005 难度分布调整

可视化滑块调整各难度等级的题目占比，总和始终为 100%。

## 5.5 难度等级定义

| 等级 | 名称 | 说明 |
|------|------|------|
| L1 | 初级 | 基础概念与语法 |
| L2 | 中级 | 理解与应用 |
| L3 | 高级 | 分析与综合 |
| L4 | 专家 | 架构与设计 |
| L5 | 大神 | 深度与创新 |

## 5.6 数据文件规范

**存储位置**：`{workspaceRoot}/{job_role}/interviews/{date}-{name}/questions.md`

```markdown
---
interview_id: int-20260417-001
candidate_name: 张三
job_role: frontend_dev
total_questions: 15
difficulty_distribution:
  L1: 3, L2: 4, L3: 4, L4: 3, L5: 1
---

# 面试问题清单 - 张三

## L1 基础题
### Q1: HTML语义化标签有哪些？
- 类型: HTML基础
- 答案: header/footer/nav/article/section/aside等

## L2 理解题
### Q3: Vue的响应式原理是什么？
- 类型: 框架原理
- 答案: Vue2使用Object.defineProperty...
```

## 5.7 非功能需求

- 生成响应时间：流式返回，首字延迟 < 3秒
- AI 调用使用 API Key 配置管理，仅发送必要文本
- 生成失败支持重试
- 问题清单完全存储在本地
