# 06 - 面试执行模块

## 6.1 模块概述

面试执行模块负责管理面试的整个执行流程，包括创建面试记录、展示面试问题、记录候选人回答、语音转录、面试计时和自动保存等功能。支持全屏面试模式，左右分栏布局（简历 + 问题）。

## 6.2 模块目标
- 提供完整的面试流程管理
- 按类型和难度排序展示问题
- 实时记录候选人回答（文本/语音）
- 支持自动保存和定时保存
- 提供面试计时功能

## 6.4 功能详细说明

### IE-001 创建面试记录

**输入**：jobRole + candidateName + interviewer + interviewDate + targetLevel + jdId（可选）+ difficultyLevels（可选）

**处理逻辑**：验证工作空间 → 生成面试ID → 创建目录 `{date}-{name}/` → 创建 interview.md

### IE-002 获取面试列表

**输入**：jobRole + 可选筛选条件（状态、关键词）

**处理逻辑**：遍历 interviews/ 目录 → 读取各面试的 interview.md → 按条件筛选 → 返回列表

### IE-003 获取面试详情

**输入**：interviewId

**处理逻辑**：读取面试目录下所有文件 → 合并返回完整面试数据

### IE-004 开始面试

**处理逻辑**：更新状态为 in_progress → 记录 started_at → 进入全屏面试页面 → 开始计时

**全屏面试布局**：
- 左侧：简历面板（可拖拽调整宽度）
- 右侧：问题列表（按类型分组，组内按难度排序）

### IE-005 记录回答

**输入**：interviewId + questionId + answerContent

**处理逻辑**：读取 answers.md → 添加/更新答题记录 → 触发自动保存

### IE-006 语音录入

**处理逻辑**：
1. 调用浏览器 MediaRecorder API 开始录音
2. 停止录音后获取音频 Blob
3. 调用 AI 语音模型（/audio/transcriptions）进行语音转文字
4. 流式返回转录文本
5. 将转录文本填入回答区域

### IE-007 自动保存

**保存策略**：
- 防抖保存：内容变更后 1 秒自动保存
- 定时保存：每 30 秒强制保存一次
- 保存内容：answers.md（答题记录）、elapsed_seconds（已用时长）

### IE-008 面试计时

记录面试已用时长（elapsed_seconds），实时显示在界面上。

### IE-009 结束面试

**处理逻辑**：更新状态为 completed → 记录 completed_at → 计算 duration_minutes → 保存

## 6.5 面试生命周期

```
pending ──▶ in_progress ──▶ completed
   │                            │
   └──────── cancelled ─────────┘
```

| 状态 | 说明 |
|------|------|
| pending | 面试已创建，尚未开始 |
| in_progress | 面试进行中（记录 started_at、elapsed_seconds） |
| completed | 面试已完成（记录 completed_at、duration_minutes） |
| cancelled | 面试已取消 |

## 6.6 数据文件规范

**interview.md 格式**：
```markdown
---
interview_id: int-20260417-001
candidate_name: 张三
interviewer: 面试官A
job_role: frontend_dev
target_level: P5
status: completed
jd_id: jd-20260417-001
difficulty_levels: [L1, L2, L3, L4, L5]
started_at: 2026-04-17T10:00:00Z
completed_at: 2026-04-17T11:30:00Z
duration_minutes: 90
elapsed_seconds: 5400
---

# 面试记录 - 张三
（面试基本信息）
```

**answers.md 格式**：
```markdown
---
interview_id: int-20260417-001
candidate_name: 张三
---

# 面试答题记录 - 张三

### Q1: HTML语义化标签有哪些？
- 难度: L1
- 类型: HTML基础
- 回答内容: HTML5提供了header/footer/nav...
- 面试官评分: 8
- AI评分: 4
```

## 6.7 非功能需求

- 创建响应时间：< 1秒，记录回答：< 1秒
- 支持面试暂停和继续，自动保存进度
- 面试数据完全存储在本地，支持离线记录
