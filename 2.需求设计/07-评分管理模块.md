# 07 - 评分管理模块

## 7.1 模块概述

评分管理模块负责面试官对候选人答题情况的评分。支持按题目逐一评分、AI 辅助评分、面试官综合评价维度评分（沟通、项目、潜力、价值观）以及手动加分。评分数据存储在 answers.md 和 assessment.md 中。

## 7.2 模块目标
- 提供标准化的评分流程
- 支持按题目逐一评分
- 提供 AI 辅助评分参考
- 支持面试官综合评价维度
- 支持手动加减分

## 7.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| SM-001 | 获取评分列表 | 获取所有题目的评分状态 | P0 |
| SM-002 | 提交评分 | 提交单道题目的面试官评分 | P0 |
| SM-003 | AI辅助评分 | AI 根据参考答案自动评估（1-5分） | P0 |
| SM-004 | 批量AI评分 | 批量调用 AI 对所有题目评分 | P1 |
| SM-005 | 面试官评价 | 沟通/项目/潜力/价值观四维度评分 | P0 |
| SM-006 | 手动加分 | 面试官根据整体印象加减分（-5~+5） | P1 |
| SM-007 | 获取维度得分 | 按考察维度汇总加权得分 | P0 |
| SM-008 | 评分统计 | 获取评分统计信息 | P1 |

## 7.4 功能详细说明

### SM-001 获取评分列表

读取 answers.md 和 questions.md，合并返回题目和评分状态。

### SM-002 提交评分

**输入**：
```typescript
interface SubmitScoreInput {
  interviewId: string
  questionId: string
  score: number  // 0-10
}
```

**处理逻辑**：验证评分范围（0-10）→ 读取 answers.md → 更新评分 → 原子写入

### SM-003 AI辅助评分

**处理逻辑**：
1. 读取题目、参考答案、候选人回答
2. 调用 AI 模型评估回答质量
3. 返回 1-5 分的 AI 评分
4. 写入 answers.md

### SM-004 批量AI评分

遍历所有已答题但未评分的题目，依次调用 AI 评分。

### SM-005 面试官评价

**评价维度**：

| 维度 | 分值范围 | 说明 |
|------|---------|------|
| 沟通能力 | 0-10 | 沟通表达与逻辑清晰度 |
| 项目能力 | 0-10 | 项目经验与技术深度 |
| 发展潜力 | 0-10 | 学习能力与成长空间 |
| 价值观 | 0-10 | 价值观与团队匹配度 |

### SM-006 手动加分

分值范围 -5 ~ +5，面试官根据整体印象调整。

### SM-007 获取维度得分

**综合得分计算**：
```
综合得分 = 候选人平均分 + 手动加分 + 面试官评价平均分

其中：
  候选人平均分 = 各题面试官评分的平均值
  面试官评价平均分 = (沟通 + 项目 + 潜力 + 价值观) / 4
```

**维度得分**：按工作空间配置的考察维度权重，汇总各维度下题目的平均得分。

### SM-008 评分统计

计算：总题目数、已评分数、平均分、最高分、最低分。

## 7.5 非功能需求

- 获取列表：< 2秒，提交评分：< 1秒，AI评分：< 5秒/题
- 评分修改日志记录
- 评分数据完全存储在本地，支持离线评分
