# 09 - 报告生成模块

## 9.1 模块概述

报告生成模块负责将面试过程中的所有数据整合生成一份完整的面试报告。报告以 Markdown 格式存储，支持 default / detailed / summary 三种模板。重新生成时自动备份原报告。

## 9.2 模块目标
- 整合面试全流程数据生成报告
- 提供标准化的报告模板
- 支持报告预览
- 支持报告版本管理

## 9.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| RG-001 | 生成报告 | 生成完整的面试报告 | P0 |
| RG-002 | 获取报告 | 获取已生成的报告内容 | P0 |
| RG-003 | 重新生成 | 重新生成报告（备份原文件） | P1 |

## 9.4 功能详细说明

### RG-001 生成报告

**输入**：interviewId + template（default/detailed/summary）

**处理逻辑**：
1. 验证面试已完成、评分已完成、等级评定已完成
2. 读取各模块数据文件（resume.md、questions.md、answers.md、assessment.md、interview.md）
3. 使用模板整合数据
4. 生成 report.md 保存

**报告结构**：
1. 基本信息（候选人、工种、目标职级、面试日期）
2. 简历摘要
3. 问题清单
4. 答题详情（每题的问题、回答、评分）
5. 评分分析（维度得分、加权汇总）
6. 职级评定（推荐职级、综合得分）
7. 录用建议

### RG-002 获取报告 / RG-003 重新生成

读取 report.md，重新生成时自动备份原报告为 `.bak` 文件。

## 9.5 数据文件规范

**存储位置**：`{workspaceRoot}/{job_role}/interviews/{date}-{name}/report.md`

```markdown
---
interview_id: int-20260417-001
candidate_name: 张三
job_role: frontend_dev
target_level: P5
recommended_level: P5
comprehensive_score: 7.5
hiring_recommendation: 通过
generated_at: 2026-04-17T11:35:00Z
---

# 面试报告 - 张三

## 一、基本信息
（候选人、工种、目标职级、面试日期）

## 二、简历摘要
（教育背景、工作经历、技能栈、项目经验）

## 三、面试问题清单
（按难度分级）

## 四、答题详情
（每道题的回答内容、评分）

## 五、评分分析
（各维度得分、综合得分）

## 六、职级评定
（推荐职级、优势分析、不足分析）

## 七、录用建议
（录用建议、录用理由）
```

## 9.6 非功能需求

- 报告生成：< 5秒
- 支持报告版本管理（.bak 备份）
- 报告完全存储在本地，支持离线查看
