# 11 - 语音模块

## 11.1 模块概述

语音模块负责面试过程中的语音录入和转文字功能。基于浏览器 MediaRecorder API 进行录音，通过 AI 语音模型（OpenAI 兼容的 /audio/transcriptions 接口）将音频转为文字，支持 SSE 流式返回转录结果。

## 11.2 模块目标
- 支持浏览器端录音
- AI 语音转文字
- 流式返回转录结果
- 可配置独立的语音模型

## 11.3 功能列表

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| VC-001 | 开始录音 | 启动浏览器录音 | P1 |
| VC-002 | 停止录音 | 停止录音并获取音频 | P1 |
| VC-003 | 语音转文字 | AI 将音频转为文字 | P1 |
| VC-004 | 录音状态查询 | 查询当前录音状态 | P2 |

## 11.4 功能详细说明

### VC-001 开始录音 / VC-002 停止录音

基于浏览器 MediaRecorder API，支持开始/停止录音，返回音频 Blob。

### VC-003 语音转文字

**处理逻辑**：
1. 获取录音音频 Blob
2. 调用 AI 语音模型的 `/audio/transcriptions` 接口
3. SSE 流式返回转录文本
4. 将转录文本填入面试回答区域

**语音模型配置**：独立的 AI 语音模型配置（provider、apiKey、baseURL、model），与问答模型分开管理。默认使用 qwen3-asr-flash。

### VC-004 录音状态查询

查询当前是否正在录音。

## 11.5 非功能需求

- 录音启动：< 1秒，转文字：流式返回
- 语音模型 API Key 独立配置
- 音频数据本地处理
