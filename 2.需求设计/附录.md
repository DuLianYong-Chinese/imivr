# 附录

## A. 术语表

| 术语 | 说明 |
|------|------|
| JD | Job Description，岗位描述/招聘需求 |
| LLM | Large Language Model，大语言模型 |
| P3-P7 | 职级体系，从初级到专家 |
| L1-L5 | 难度等级，从初级到大神 |
| Job Role | 工种类型，如前端开发、后端开发、产品经理等 |
| 考察维度 | 各工种核心能力评估维度 |
| Front Matter | Markdown 文件头部的 YAML 元数据 |
| SSE | Server-Sent Events，服务端推送事件（流式响应） |
| ASR | Automatic Speech Recognition，自动语音识别 |
